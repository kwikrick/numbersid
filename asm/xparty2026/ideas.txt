Basic idea:

We let our tool (numbersid C code + Python?) generate assemby code (Kickass) for calculating 
sequences and updating the dirty flags and lists of dirty sequences/parameters. 
The generated code is (hopyfully) somewhat compact and crunchable by exomizer.

The static code then calls the generated code for each dirty sequence and 
each dirty parameter. 
  


Operations:

Sequence structure:

output_variable = input_variable [operand varonum]*

lower level:

read_value_to_accumulator value:word
	lda #<value
	sta ACCUMULATOR
	lda #>value
	sta ACCUMULATOR+1


read_variable_to_accumulator variable:byte
	ldx #variable
	lda variables_low,x
	sta ACCUMULATOR
	lda variables_high,x
	sta ACCUMULATOR+1


read_value_to_operand value:word
	lda #<value
	sta OPERAND
	lda #>value
	sta OPERAND+1

read_variable_to_operand variable:byte
	ldx #variable
	lda variables_low,x
	sta OPERAND
	lda variables_high,x
	sta OPERAND+1
